# OpsPilot

OpsPilot is an evaluation-driven LLM agent for automating multi-step customer support workflows.

## Current Status

Early development.

### Implemented
- FastAPI backend
- Pydantic domain models
- Order service layer
- Agent-facing tool abstraction
- Dynamic tool registry
- Structured tool requests
- Business-rule validation

### Planned
- LLM tool calling
- PostgreSQL
- RAG and vector search
- LangGraph orchestration
- Automated evaluation
- MCP integration
- Local LLM inference
- Observability and deployment
